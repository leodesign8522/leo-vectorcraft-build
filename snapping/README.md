## 本轮实现

- 从 Core 公共构建移出整组锚点吸附移动、彩色辅助线、Shift 拖点、延长线和参考线吸附增强。
- 单独入口 `snapping/apply.py`；旧兼容补丁归入 `snapping/adapters/`，不再由 Core 调用。
- 新建点吸附解析器 `snapping/leo_snapping.rs`，替换旧的点目标决策函数。
- 节点捕捉范围保持屏幕像素换算；释放半径是捕捉半径的 1.5 倍，减少相邻节点之间跳动。
- 锁定状态归属一次目标快照；方向约束优先，切入 Shift 约束清除旧节点锁。
- 保留并接入 Shift 水平/垂直/45°、任意角延长线交点、可见参考线吸附。
- 原线方向支持双向锁定：向外延长、向内缩短及越过固定端点时均显示黄色吸附；青色预览随拖动方向显示，两个方向均可吸附真实边交点。
- 节点目标优先于普通路径投影；辅助线关闭后仍能计算吸附。
- 吸附专属设置位于 Edit > Preferences > Leo Snapping。
- 构建前检查 Core 没有加载吸附模块、增强色彩字段、延长线增强或饼菜单钩子。

## 首版范围与下一阶段

这不是 Affinity 吸附的完整复刻。候选几何采集、对象移动与缩放仍使用官方实现；颜色与手势接入层来自先前版本。新写部分是点目标解析与节点锁定，仍需 Windows 实机手感验证。

后续重点：Affinity 式吸附面板；候选列表与图层范围；独立启停各类吸附；对象移动与缩放统一求解；控制柄、多节点、密集场景与性能验证。未实现项目不得标记为已完成。

## 安装方式

当前官方插件接口不能承担这套画布输入与吸附替换，因此首版通过完整主程序编译交付，不是能叠装的 DLL 插件。

Core 与 Snapping 各自提供便携包和针对官方 v0.21.0 的覆盖安装器。Snapping 版包含配套 Core v0.11.1；使用它无需再安装 Core。切回 Core 将移除自定义吸附增强。安装器不会删除配置。

只使用对应版本安装包；以 GitHub Actions 实际测试和编译结果为准，预览源码提交不代表已经生成安装器。

## v0.1.2 旋转贴边

R 工具、选择框和自由变换旋转按被拖端点/角点的固定半径圆弧捕捉其他路径的真实直线或曲线边，保留轴心、角度读数、尺寸及 Shift 45°约束。旋转过程中不调用普通水平/垂直对齐提示；实际命中才显示黄色旋转贴边提示，原有拖点及移动对齐提示不变。有限路径以外的延长部分不捕捉，所选对象不吸附回自己的原始边。节点/边锁定使用较大的释放范围，显示关闭时仍可计算几何。

此规则是拖住的点落在目标边上；不表示物体的整条边自动平移并重合。文字/符号的视觉轮廓仍受原生路径采集范围限制，当前优先处理矢量路径。自动测试不替代用户文件的 GUI 手感验收。
