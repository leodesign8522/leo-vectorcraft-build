# Core Bridge 集成吸附模块

2026-11-05 起，Snapping 随 **Leo Design Core Bridge v0.12.0** 一起构建和交付，适配官方 VectorCraft **0.21.1**。不再提供独立 Snapping 安装包。

## 功能

- v0.12.1：拖动单个可编辑文字对象时，智能参考线按实际字形外缘对齐。抓住字形轮廓或转曲对象的锚点，可以吸附到其他对象的真实锚点或路径边。直接选择工具拖动节点时，普通对齐提示收短，实际接触点显示标记。
- 串接文字框和没有矢量轮廓的文字沿用对象框。网格和像素吸附保留原有优先级。

- Ctrl 整组锚点移动、节点捕捉与释放锁定、屏幕像素容差。
- Shift 页面水平/垂直/45°约束及真实路径交点吸附。
- 原线方向双向延长/缩短及任意角交点。
- 可见参考线吸附，延长线预览与命中反馈。
- 十类辅助线颜色自定义与三套预设；关闭显示仍保留相应几何计算。
- R 工具、选择框和自由变换的旋转端点/角点贴真实路径边；旋转中抑制普通轴向红线，命中显示黄色提示。
- 设置入口：Edit > Preferences > Leo Core Bridge 吸附。

## 边界

旋转吸附是被拖动的点沿固定半径轨迹落在目标边上，不是整条边自动平移重合。文字/符号视觉轮廓仍受原生几何采集范围限制。

对象移动/缩放和候选几何采集仍部分复用官方实现；Affinity 完整候选管理和完整设置面板尚未实现。

## 交付与删除项

只有 Core Bridge 安装器和便携包，二选一使用；覆盖安装仅接受官方 0.21.1。

截图剪贴板增强（审阅清单 34～37）已移出构建，外部截图粘贴使用官方实现。快捷键备份菜单（54）已删除，工作区导入导出、官方快捷键及文字字体兼容保留。饼菜单继续停用。

自动测试和编译结果以对应 Actions 为准，不等于用户文件的 Windows GUI 手感验收。
