## 安装与边界

- 产物：便携版，以及只接受官方 v0.20.0 的覆盖安装器。两者任选一个。
- 安装器只写程序 EXE，不删除用户配置。便携版使用独立配置目录，不宣称自动迁移原安装版设置。
- LC-004 ICC 工作空间持久化、LC-012 完整自由工作区仍是历史缺口；本次迁移不宣称补齐。
- 自动编译和测试成功不等于真实 GUI、复杂用户文件及安装体验已验收。

## v0.9.1 饼菜单便捷添加

- 原生窗口内菜单项右键 → 添加到饼菜单 → 选择菜单与方向 → 明确确认替换。
- 捕获菜单实际执行的命令及参数，不执行原命令；剪切蒙版使用完整中文名称。
- PieSlot 新增可选 params，旧 JSON 无该字段时按原来的无参数方式运行。
- 编辑命令 ID 时清除旧捕获参数，避免错用上一命令的参数。
- 保留中文同义词搜索和空结果提示。
- 新增参数 JSON 往返／旧槽位兼容回归，实际右键和 Windows GUI 仍待验收。

## v0.9.2 文件配置导入导出

- 新增原生保存／打开文件按钮，导出全部饼菜单、触发快捷键、方向与命令参数。
- 旧 JSON 数组格式兼容；验证大小、JSON 结构和快捷键冲突后才替换设置。
- 取消选择和无效文件保留当前配置；复制粘贴入口收进高级折叠栏。
- 使用原生异步文件选择入口，文件选择返回后恢复操作，不用复制粘贴。
- 新增文件往返、UTF-8 BOM、空配置、无效文件及错误导入不改变当前配置测试。

## v0.9.3 移除未通过实机验证的菜单右键添加入口

- 用户反馈原生菜单右键无法添加；移除菜单渲染器钩子、添加窗口和临时捕获状态。
- 不影响画布上的饼菜单右键触发快捷键，保留中文搜索、同义词、预设与配置文件导入导出。
- 保留 PieSlot.params 的读取和执行兼容性，避免丢失已有配置参数。
- v0.9.2 自动测试成功未覆盖真实菜单右键，本功能不再列为可用。

## v0.9.4 饼菜单命令执行排查

- 明确区分普通网格吸附 view.snapToGrid 与透视网格吸附 perspective.grid.snap；提供明确的一键替换按钮，不自动改用户命令。
- 搜索添加保留原生菜单参数及对话框入口，修复 object.align 等共用 ID 的功能变体丢参。
- 旧无方向 object.align 槽位打开对齐面板，不再空参数无效果。
- 执行时提示不可用条件与开关状态，并将执行错误显示在饼菜单编辑器。
- 新增普通/透视网格独立切换、显示网格、左/右对齐实际移动、编组/拆组和无选区反馈测试；结果以 Actions 为准。

## v0.9.5 SVG 剪贴板字体别名

- 系统粘贴优先级为 SVG/PDF/EPS；此前 CID 后缀修复仅位于 PDF 解析器。
- SVG 字体识别新增已知 CID 编码后缀和子集标签处理，先匹配已安装字体，再拆分已知字重后缀。
- 保留显式 CSS 字重/斜体优先级，不把未知连字符后缀随意删除。
- 新增 MiSans 合成 SVG 可编辑文字导入回归；用户实际剪贴板、英文分段与字距仍需最小原文件验证。
- 不宣称已修复所有 PDF/EPS/私有文字导入路径或完整段落保真。

## v0.9.6 AI 原始数据入口与多级饼菜单

- 文件菜单新增“打开 AI（原始编辑数据优先）”，通过官方原始数据解码器保留可读取的图层、分组、可编辑文字和区域文字框。
- 新增实际读取来源 editingDataRead；报告原始数据读取失败、字体警告、外观降级、框调整和溢出计数。不宣称无损导入；不包含 Illustrator 面板/自动化。
- 用户原文件仅在本地验证，不上传到源码；官方 Linux CLI 基线实际读取原始数据，报告缺失字体、框调整及溢出，不能当作新版 Windows 验收。
- 饼菜单方向可指向现有菜单或一键新建子菜单，支持最多 8 层；子菜单不必绑定快捷键。
- 原快捷键/右键甩动保留；甩入子菜单后单击选择，点中心或 Backspace 返回，Esc 关闭所有层级。
- 下级引用随重命名保留；删除目标清空引用并修正后续索引；JSON 文件备份保存全部层级，旧配置默认无下级。
- 防止无效引用、循环及超深层级；添加导航返回/叶子执行/序列化/删除/循环回归。Windows 编译及测试以 Actions 为准，实机交互待验收。
