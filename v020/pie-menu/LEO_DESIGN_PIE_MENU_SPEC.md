# Leo Design Pie Menu v0.1.0 — 产品与实现要求

适配：官方 VectorCraft v0.18.0 + Leo Design Core Bridge。独立源模块，随覆盖安装器发布。此文件是开发规范，不等于已经实现或通过测试。

## 必须实现的交互

- **菜单数量任意**：一个菜单可以绑定多种触发器；多个不同的菜单可以拥有各自的触发器、名称、颜色和 8 个扇区。
- **可视化录制快捷键**：设置页按“录制”，实际按键或按下修饰键加鼠标键即可捕获；无需手输 JSON。
- 键盘例子：`Shift+Space`；鼠标例子：`Shift+Alt+RMB`、`Shift+Ctrl+RMB`。必须都支持，也支持修改和清除。鼠标右键表示 Windows 的 secondary button，而不是依赖字符串中的 Ctrl 与 Cmd 等价假设。
- **默认右键菜单不变**：普通右键继续原本的 VectorCraft 上下文菜单；只有与饼菜单绑定的组合才拦截。
- 鼠标触发：按下组合键 + 右键 → 中心弹出 8 扇区 → 移动鼠标指向扇区 → 松开右键执行；无明确指向时松开不执行。Esc 或左键点空白取消。
- 键盘触发：键盘快捷键弹出菜单，鼠标选扇区并单击执行。Esc 取消。可在未来配置按住键与松开执行模式。
- **编辑器里“添加功能”**：提供搜索框和分类（工具、编辑、对象、路径、对齐、颜色、视图、面板等），查询原生 `vectorcraft_engine::command_specs()`、`menus::UI_COMMANDS` 和 `vectorcraft_tools::catalog::all_tools()`，即复用 `palette::items()` 的命令目录。
- 点击一个空扇区 → 搜索 VectorCraft 功能 → 单击“添加”绑定。显示真实命令名/ID；已绑定项目可替换、清除、调换、改显示名。
- 工具 `tool:<id>` 使用 `tool.select {tool:id}`，面板 `panel:<id>` 使用 `window.panel {panel:id}`；其余菜单命令走 `menus::invoke`，以便复用已有参数对话框、选择状态限制及撤销流程。
- 配置随用户首选项保存，但不存于具体画板文档；设置页支持 `Export JSON` 和 `Import JSON`，导入时验证格式、命令 ID 以及冲突。

## 冲突处理与安全

- 录制时检查同一用户饼菜单的重复键，拒绝覆盖其他饼菜单，除非明确先移除旧绑定。
- 与现有快捷键/画布导航冲突，特别是 Shift+Space，应提示“现有功能：... / 保留原绑定 / 覆盖为饼菜单”；不得悄悄占用。
- 文本编辑、搜索框、对话框、IME 组合输入时不触发饼菜单。
- 不拦截无修饰键的普通右键；即使用户试图设置纯 RMB，也应提示冲突并禁止覆盖（除非以后专门添加“替代默认右键菜单”开关）。
- 选中对象为空时显示可用功能；不可用项目不执行，避免抹掉选择。
- 每一帧不重复触发鼠标/键盘事件；执行动作后关闭菜单，撤销仍由原生命令系统处理。

## 架构建议

- 主模块：`crates/ui-egui/src/leo_pie_menu.rs`。数据和绘制、交互及设置窗口以子模块拆开，避免单文件过大。
- 原生画布鼠标入口：`crates/ui-egui/src/canvas/context.rs`，在 `resp.context_menu(...)` 前识别匹配的右键组合，避免同时弹出两个菜单。
- 键盘入口：`crates/ui-egui/src/shortcuts.rs`，只有在焦点和工具状态允许时才拦截用户绑定的快捷键。
- 状态保存：`UiState` 内 `leo_pie_menus` serde 默认兼容旧 ui.json；瞬时打开/编辑/录制状态标注 `#[serde(skip)]`。
- GUI 绘制：egui 自定义 8 扇区浮层并用原生命令系统执行；支持高 DPI 和窗口边缘自动防溢出。
- 单独的用户配置版本号（schemaVersion），为以后自定义数量、子菜单和颜色提供迁移路径。
- 第 1 阶段先做真实 8 方向 / 录制 3 类触发器 / 搜索命令绑定 / JSON 配置，不把未开发的二级菜单、全局鼠标监听包装成已完成。

## 必须通过的验收测试

1. 绑定 Shift+Space：在空白画布可用；文本编辑时不触发；若导航已有同键给出冲突提示。
2. 绑定 Shift+Alt+RMB：触发饼菜单，不触发普通右键；移动到扇区并松开只执行一次。
3. 绑定 Shift+Ctrl+RMB：和上个快捷键能够分别打开不同菜单，同一菜单也能同时绑定多个触发方式。
4. 普通右键完全保持原菜单。
5. 可以从搜索列表一键绑定：编组、拆组、镜像、对齐、切换工具、打开面板。
6. 退出重启、切换工作区后配置仍在；JSON 导出/导入后结果一致。
7. 录制 Escape 取消；重复/冲突不会静默覆盖；快速双击、点击画布或失焦不会意外执行。
