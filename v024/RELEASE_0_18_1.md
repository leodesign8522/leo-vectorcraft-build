# Leo Design Core Bridge 0.18.1 / VectorCraft 0.24.1

- 使用 VectorCraft 0.24.1 原生吸附与标尺参考线图层管理。吸附容差与辅助线颜色可在官方首选项中调整。
- 保留 Illustrator 双向发送和可编辑 AI 导出，以及 0.17.3 分支中的文字段落对齐和图层顺序修复。
- 保留文字选框、文字框高度模式、文字吸管、组内选择、整组拖动、活动圆角、工作区 JSON、动作快捷键、文档统计、图像与 ICO 导出。
- 图标飞出面板缩放使用 VectorCraft 0.24.1 的原生布局。旧版自研飞出面板尺寸使用的独立字段不再应用，工作区仍可导入。
- Windows 安装器同时安装 Core Bridge 和 Illustrator 发送器，启动快捷方式为 **Leo Design VectorCraft 0.24 Bridge 0.18.1**。
