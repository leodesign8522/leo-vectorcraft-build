# Leo Design Core Bridge 0.20.1 / VectorCraft 0.24.1

- 直接选择工具拖动单个节点时，已吸附的延长线可与其他图形上可见锚点的水平或垂直坐标相交。命中时显示黄色延长线、蓝色对齐线和目标锚点高亮。
- 延长线出现后按住 Alt 可以锁定其方向，再沿线寻找目标。实际锚点和边缘交点优先。

工具栏新增四个 Leo Design 几何工具，长按按点画圆图标展开。
- 按点画圆：依次点两点定直径，Tab 切换到三点定圆。
- 相切圆：先选第一条边，再指向并点击第二条边。Shift 临时使用固定半径，F 切换模式，数字输入半径（pt），Tab 切换候选，Alt 确认时插入切点。
- 曲率圆：指向贝塞尔曲线查看圆心和半径，点击创建。Shift 显示并创建另一侧的等半径圆。
- 按点圆弧：先定起点和终点，再点弧上的第三点。Tab 切换到终点切线模式。
- Esc 取消当前绘制，保留 0.19.1 的吸附工具。
