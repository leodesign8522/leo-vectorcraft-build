# Leo Design Core Bridge 0.19.1 / VectorCraft 0.24.1

- R 旋转工具可将斜边贴合可见的标尺参考线，锁定的参考线也可作为目标。命中时高亮实际重合的边段。
- 在「首选项 → 智能参考线」勾选 Leo Design 吸附使用自研吸附，取消勾选切回官方吸附。默认启用 Leo Design 吸附。
- 自研吸附支持节点、直线、贝塞尔曲线、参考线与路径交点、延长线、旋转与缩放。命中时标出实际对齐目标。
- 保留官方标尺参考线的图层管理及 Core Bridge 的 Illustrator 双向发送、可编辑 AI 导出、组内选择和其他既有增强。
- 安装后从开始菜单启动 **Leo Design VectorCraft 0.24 Bridge 0.19.1**。
