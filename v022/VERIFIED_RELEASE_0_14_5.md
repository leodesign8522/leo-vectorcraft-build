# Leo Design Core Bridge 0.14.5 验证记录

VectorCraft 0.22.0 / Windows x64 / Leo Snapping Engine 1.7。

## R 旋转边方向吸附

本次适用于 **R 旋转工具，指定旋转中心后拖动**。0.14.4 原有逻辑只会对鼠标位置作普通点/边界吸附，没有求解所选物体直边与参照直边之间的真实旋转角度。

本次新增以自定义中心为固定点的刚性旋转吸附：

- 当前视野内其他矢量对象的真实直边提供方向参照；隐藏对象与曲线不当作直线方向，所选物体/整组的自身几何被排除。
- 命中时所选直边与目标方向精确平行。两边位于同一直线时显示 **“旋转吸附 · 共线”**，否则显示 **“旋转吸附 · 平行”**。保持中心和物体结构，不通过平移凑齐边缘。
- 黄色虚线和深色底标签仅在真实角度命中时出现；角度读数规范到常用的 ±180° 范围。
- 捕获 8px、释放 12.8px，按鼠标/所收集直边端点距中心的最大半径，换算为旋转带来的屏幕位移；随缩放变化，不固定为某个角度数。
- 原始边、参照和角度锁来自拖动开始时的快照。捕获参照要求当前可见；已捕获的目标可保持到释放，平移画布后释放则不重新捕获视野外参照。
- Shift 保留原有固定 45° 旋转并退出方向吸附；Alt 保留复制，原对象不变。仅变换图案时不显示轮廓已命中的提示。
- 支持整路径以及全部锚点选中的路径；部分锚点选择继续使用原生变换行为。V 工具的边框角外旋转保持原有行为。
- 保留 0.14.4 的中间手柄缩放吸附和原有黄色延长线、节点/对象/编组移动功能。

## 使用

先保存文档，安装后从 **Leo Design VectorCraft 0.22 Bridge 0.14.5** 新快捷方式启动；关于显示 Core Bridge 0.14.5 / Snapping Engine 1.7。

开启智能参考线，选中物体，按 **R**，单击指定中心，再拖动旋转。靠近目标边方向时出现黄色旋转吸附提示。要让两边共线，可把中心设在共同端点；只对齐方向时会提示平行。Shift 使用固定角度，Alt 拖动并释放生成副本。

默认目录：`%LOCALAPPDATA%\Programs\Leo Design\VectorCraft-0.22-Bridge-0.14.5`。
