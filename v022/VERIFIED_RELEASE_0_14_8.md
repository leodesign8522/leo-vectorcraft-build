# Leo Design Core Bridge 0.14.8 验证记录

VectorCraft 0.22.0 / Windows x64 / Leo Snapping Engine 1.8。

## 本次升级

- **I 吸管**：选目标文字后按 I、点击源文字，复制高度模式和贴合字形选框开/关。目标内容、位置、框宽保持不变；自动高度按目标内容重新计算，固定高度保留目标当前高度。点文字没有高度模式，不会把段落文字转换成点文字。非文字来源不覆盖文字模式。
- 吸管设置新增独立的“文字框高度模式”和“贴合字形选框”勾选项，默认同时勾选 Picks Up / Applies。继续支持原来的字体、字号、段落与外观采样。文字编辑中的局部选区只处理原有字符/段落属性，这两项对象设置通过选择整段文字来采样；追加外观不改它们。
- **高度状态**：选中的“✓ 自动贴合高度”或“✓ 固定框高”持续高亮，并显示“当前”状态。多选或普通组内模式不一致显示“混合状态”；无段落文字时禁用。已有 Shrink Text 模式单独标明，不误显示为前两种之一。
- **默认值**：新建文字默认开启贴合字形选框，新建段落文字默认自动高度。旧偏好首次升级时迁移一次自动高度默认值；之后用户手动关闭仍可保存。旧文件和导入对象原有模式不被批量重写。
- **网格优先**：开启 Snap to Grid 时暂停智能几何、延长线、对象对齐和 R 方向吸附，不出现抢吸附或残留命中线。关闭网格后恢复原有智能吸附偏好；不强行改掉 Smart Guides 的已保存开关。网格优先于同时传入的像素选项；只开像素时保留原有几何优先行为。已有捕获在切到网格时释放。
- **Shift＋空格**：不再触发旋转视图，按空格方式平移；普通空格平移、Ctrl/Cmd＋空格缩放和显式 Rotate View 工具保留。R 对象旋转不受这个快捷键改动影响。
- 保留 0.14.7 的字形边界对齐：新建文字直接按字形居中；旧文字可开启贴合后使用。
