# Leo Design Core Bridge 0.14.4 验证记录

官方 VectorCraft 0.22.0，Windows x64；Leo Snapping Engine 1.6。

## 本次修复

修复 **选择工具拖动边框中间小方块缩放宽度/高度** 时不能吸附的问题。这与整物体移动、白箭头拖节点是不同的操作入口。

旧缩放仍走官方 PointSnap/Targets::for_scale 通道：超过 20,000 个背景锚点后后续对象目标被漏掉；网格或像素开启时又会跳过几何目标。旧版 0.14.3 实际程序的合成负对照中，四边 × 无网格/网格/像素共 12 项均未贴到目标直线。

新缩放入口使用完整的不可变场景快照，在缩放边附近查询实际节点、有限直线/Bezier 和画板边缘；几何命中优先，未命中才使用网格/像素回退。按缩放本身允许的方向求交，不把缩放当成节点自由移动：

- 左/右/上/下中间手柄支持 8 屏幕像素捕获、12.8 屏幕像素释放。
- 普通缩放保持对侧边；Alt 保持中心；Shift 保持比例；修改修饰键时旧锁重新计算。
- 旋转边框使用自身坐标轴，有限 Bezier 按真实曲线求交。
- 仅真实捕获显示反馈。普通路径命中保留路径颜色；0.14.3 的延长线继续使用黄色“延长线吸附”。本次没有把边框缩放改成延长线搜索。
- 关闭智能参考线时不继续进行对象边界对齐；显式启用的吸附到点/参考线仍按其设置工作。
- 扩大原生选择工具回归后，补修参考线在捕获范围外拉动、Shift 等间距目标列表缺失两项旧问题。
- 缩放使用 Leo 固定 8px 捕获契约，替代旧的 Smart Guides 0/4px 缩放捕获断言；显示/测量偏好仍受原生测试覆盖。

## 安装和使用

先保存当前文档。安装后从 **Leo Design VectorCraft 0.22 Bridge 0.14.4** 新快捷方式启动；关于显示 Core Bridge 0.14.4 / Snapping Engine 1.6。

开启智能参考线，用 **V 选择工具拖动边框左/右/上/下中间小方块**，让缩放边靠近目标路径。默认目录：`%LOCALAPPDATA%\Programs\Leo Design\VectorCraft-0.22-Bridge-0.14.4`。
