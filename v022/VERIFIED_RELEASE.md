# Leo Design Core Bridge 0.14.3 验证记录

VectorCraft 0.22.0 / Leo Snapping Engine 1.5，Windows x64。

## 本次升级

A 白箭头拖动单个节点时，支持相邻原直边、当前路径非相邻直边，以及其他可见矢量对象直边的双向延长线。非相邻边与其他对象只参照当前视野内的真实直边；范围随平移/缩放更新。已吸住的目标保持到正常释放，释放后不能重新捕获视野外的参照。相邻原边方向继续按拖动起点冻结。

命中统一使用亮黄色（RGB 255,214,0）虚线、深色描边圆标和深色底“延长线吸附”文字。它与真实节点/路径命中区分；只有节点确实被投影到延长线上才显示。

- 8px 捕获，12.8px 释放，随缩放换算；捕获锁直接保存目标直线，避免候选变化串线。
- 真实节点、有限直线/Bezier 和画板边缘保持优先；Shift 保留原有方向锁定，不叠加延长线约束。
- 原边方向和其他对象几何均取拖动开始时的快照，目标不追随预览改变。
- 外部直边按方向和偏移建立索引，经过索引筛选后精确投影；没有 20,000 条截断。
- 绘制的虚线长度最多约 512 屏幕像素，数学延长线仍然双向，不生成超长虚线拖慢渲染。
- 隐藏对象和曲线不当作外部直边延长线。普通对象/编组移动和 Alt 复制保留原有行为。

## 本机实测

使用隔离便携副本和合成图形，通过原生控制接口发送实际工具事件：

- 四个顶点、各自两条邻边、延长和回缩共 16 项通过，固定节点不变，提交及撤销/重做通过。
- 其他对象直边的两端延长线通过，目标对象不变；捕获保持、释放、再次捕获通过。
- 当前路径非相邻边的延长线通过。
- 视野外参照不捕获、拖动中缩放使参照进入视野后捕获、已锁定参照移出视野保持、释放后不再捕获均通过。
- 已查看实际程序截图：亮黄色描边虚线、圆标及深色底中文标签清晰显示。
- 保留原有大文档节点/整组移动、Shift、网格、Shift+Alt 复制及本地恢复副本的几何吸附检查。

0.14.2 同一负对照中，当前图形的 16 个方向通过，但跨对象目标停在指针位置；本次测试能检测旧版缺失。

索引专项样本：20,005 条直线建立索引约 31.66ms，1000 次查询共约 2.96ms（Windows CI 测试配置，无界面索引查询样本）。这只是该样本的构建/查询耗时，不是整体画布帧率，也不是所有大文档的性能保证。

## 安装和使用

先保存当前未保存的文档。安装后从 **Leo Design VectorCraft 0.22 Bridge 0.14.3** 新快捷方式启动；关于显示 Core Bridge 0.14.3 / Snapping Engine 1.5。

开启 **视图 → 智能参考线**，用 **A 白箭头拖动单个节点，无需 Shift**。出现黄色“延长线吸附”表示已命中。

默认目录：`%LOCALAPPDATA%\Programs\Leo Design\VectorCraft-0.22-Bridge-0.14.3`。快捷方式启动新实例，保留旧版本目录。
